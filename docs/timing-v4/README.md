# V0 计时器调整验证

本轮只调整测量工具，生产模型源文件未改。以下为 protocol 4 的独立打点校准，不能当成模型优化收益；本目录保留校准当时的实现与记录。

## ITL 开关校准

固定六条 ShareGPT；A=关闭中间 ITL 打点，B=正常打点；ABBA+BAAB，每进程真实预热一次、每条三次。每模式每条 12 次，共 144 次测量。

不开启 ITL 的主指标 1686.835061 ms，开启 ITL 为 1686.169849 ms，观测变化 -0.039436%。主指标为各请求总时间中位数的均值。

四组成对进程变化：+0.580001%, -0.224059%, +0.053100%, +0.130049%。

关闭/开启模式内的进程均值相对极差分别为 0.933086% / 0.486582%。

**结论：本次重复次数下未稳定分辨出额外 ITL 打点耗时。** 不代表开销为零，也不提供开销上界。差值不从正式成绩中扣除。所有 144 条记录的生成 IDs 在两种模式之间、与可信 V0 旧记录之间均一致。
