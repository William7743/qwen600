To edit an array that is within an object, you first need to access the array by specifying its key in the object. Once you have accessed the array, you can use any of the methods available for JavaScript arrays to edit it.

Here's an example object with an array inside:
```javascript
const obj = {
  name: "John",
  hobbies: ["reading", "running", "cooking"]
};
```
To edit the `hobbies` array, you can use the index to access a specific element in the array, and then assign a new value to it, like so:
```javascript
// change the second element of the hobbies array
obj.hobbies[1] = "swimming";
```
You can also use array methods to add or remove elements from the array:
```javascript
// add a new hobby to the array
obj.hobbies.push("hiking");

// remove the first hobby from the array
obj.hobbies.shift();
```
Remember that when you modify an array that is within an object, the object itself will be modified as well, since arrays are objects in JavaScript.
