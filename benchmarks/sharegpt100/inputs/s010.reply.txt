To add an element to an ArrayList of a specific class type in Java, you can follow the following steps:

1. Create an instance of the class to be added.
2. Get a reference to the ArrayList.
3. Call the `add()` method on the ArrayList, passing the instance of the class as the argument.

Here's an example of how to add an object of type `Person` to an ArrayList of type `ArrayList<Person>`:
```csharp
// Create a new instance of the Person class
Person person = new Person("John", 25);

// Get a reference to the ArrayList
ArrayList<Person> peopleList = new ArrayList<>();

// Add the person object to the ArrayList
peopleList.add(person);
```
In this example, the `Person` class is assumed to have a constructor that takes two arguments: a String for the person's name, and an int for their age. You can substitute your own class and constructor as necessary.
